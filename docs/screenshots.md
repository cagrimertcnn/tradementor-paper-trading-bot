# Screenshot Checklist

Recommended screenshots for portfolio presentation:

## Runtime

- FastAPI server running at `http://127.0.0.1:8000/`
- filtered signal engine running in terminal
- trade manager running in terminal
- process check with `ps aux`

## Trading Logs

- `/trades` endpoint showing closed paper trades
- `report.py` output
- optimizer output

## Security

Before uploading screenshots, make sure they do not contain:

- webhook secrets,
- API keys,
- `.env` content,
- private tokens,
- sensitive IP addresses.
